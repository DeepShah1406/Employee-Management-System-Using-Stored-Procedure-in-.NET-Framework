# ***Employee Management System Using Stored Procedure in .NET Framework***

Employee Management System (EMS) using ASP.NET and C#. The systemutilizes stored procedures in the SQL Server database for efficient CRUD (Create, Read, Update, Delete)operations on employee records.

## Overview

The Employee Management System is a web-based application built using ASP.NET and C# that allows organizations to efficiently manage employee data. Leveraging stored procedures, this system enables seamless Create, Read, Update, and Delete (CRUD) operations on employee records. Whether you’re a small business or a large enterprise, this system provides a robust solution for maintaining employee information.

## Features

- **CRUD Operations**: Perform essential CRUD operations (Create, Read, Update, Delete) on employee records.
- **Stored Procedures**: Utilize stored procedures for database interactions, ensuring security and maintainability.
- **Responsive Web Interface**: The user-friendly web interface adapts to various screen sizes and devices.
- **Data Validation**: Validate input data to maintain data integrity.
- **Search and Filter**: Easily search for employees based on criteria such as name, city, or salary.
- **Reporting**: Generate reports or export data for analysis.

## Getting Started

1. Prerequisites:
   - Install .NET Framework (if not already installed).
   - Set up a local SQL Server instance or use an existing one.

2. Clone the Repository:
   - `git clone https://github.com/your-username/Employee-Management-System.git`

3. Database Setup:
   - Create a database (e.g., `EmployeeDB`) and execute the SQL script provided in the DatabaseScripts folder.
   - Update the connection string in `Web.config` to point to your database.

4. Build and Run:
   - Open the solution in Visual Studio.
   - Build the project.
   - Run the application.
